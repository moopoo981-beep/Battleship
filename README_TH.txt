IRON TIDE II — Fleet Command / ยุทธนาวีใต้โดม
เวอร์ชัน 2.0 | ภาษาไทย | ขับเรือหนึ่งลำ + พันธมิตร AI | Co-op สูงสุด 4 คน

เข้าเล่นคนเดียว
1. คลิกขวาที่ IRON_TIDE_Battleship_Game.zip → Extract All / แยกทั้งหมด
2. เปิดโฟลเดอร์ IRON_TIDE
3. ดับเบิลคลิก START_GAME.html เปิดด้วย Chrome หรือ Microsoft Edge
4. เลือกเรือ ชื่อผู้เล่น ภารกิจ และความยาก
5. กด เริ่มภารกิจ → เข้าปฏิบัติการ

เล่นคนเดียวไม่ต้องติดตั้งและไม่ต้องใช้อินเทอร์เน็ต
START_GAME.html รวมภาพ เสียง และโค้ดที่จำเป็นไว้แล้ว ไม่มี CDN

วิธีเล่นเร็ว
W / S     เพิ่ม–ลดคันเร่ง (กดค้าง) เรือมีแรงเฉื่อยและถอยหลังได้
A / D     เลี้ยวซ้าย–ขวา
B         หยุดเครื่อง เรือจะค่อย ๆ ชะลอ
คลิก      เล็งพิกัดหรือศัตรูจากภาพ 3D หรือแผนที่ด้านขวา
Q         เปิดโซนาร์ เพื่อเห็นศัตรูที่อยู่ใกล้
G         ยิงปืนใหญ่ / กดค้างเพื่อยิงซ้ำหลังบรรจุ
L         เพิ่มหรือปลดเป้าที่ล็อก รอประมาณ 1 วินาทีให้ล็อกพร้อม
Shift+คลิก ล็อกศัตรูที่คลิก ทำซ้ำกับหลายลำ
M         ยิงจรวดแยกไปยังทุกเป้าที่ล็อกพร้อม
T         ยิงตอร์ปิโดไปพิกัด มีระบบติดตามเมื่อเลือกศัตรูที่มองเห็น
F / R     ม่านสกัดอาวุธ / ซ่อมเรือ
E         เดินเรืออัตโนมัติไปพิกัดที่เล็ง
X         ทิ้งสมอ เฉพาะเรือ VANGUARD
Space     หยุด/เดินเวลา (ออนไลน์เฉพาะเจ้าของห้อง)
Esc / H   เมนู / คู่มือในเกม

คุณบังคับเฉพาะเรือตัวเอง พันธมิตรที่ไม่มีผู้เล่นจะขับและยิงเอง
ถ้าเรือคุณจม จะชมเพื่อนและ AI ต่อจนจบรอบ ไม่ย้ายไปคุมเรือลำอื่น
ศัตรูที่ถูกทำลายหลุดจากล็อกและเรดาร์ทันที แล้วโมเดลจมและหายไป
คลิกปุ่ม เสียง เพื่อปรับดนตรี เอฟเฟกต์ เสียงหลัก หรือปิดทั้งหมด
คลิก กล้อง เพื่อเปลี่ยนมุมมอง และ ภาพ เพื่อปรับคุณภาพ ต่ำ/กลาง/สูง

เรือและร้านค้า
มีเรือให้ขับ 5 แบบ: VALOR, KIRIN, TEMPEST, AEGIS, VANGUARD
เริ่มต้นมี VALOR และ KIRIN พร้อมเครดิต 1,200 CR
เล่นจบรอบรับเครดิต ซื้อเรือ อัปเกรดเกราะ เครื่องยนต์ ปืน จรวด
ตอร์ปิโด และจำนวนเป้าล็อกได้ที่ อู่เรือ / ร้านค้า
อัปเกรดมีผลในรอบใหม่ พร้อมเติมกระสุนและชุดซ่อม
ภารกิจ 3 ให้ยืม VANGUARD ในโหมดคนเดียวได้แม้ยังไม่ได้ซื้อ

เล่นกับเพื่อน
- เปิด DEPLOY_GITHUB_TH.html เพื่อทำตามทีละขั้น
- ในวง LAN: ติดตั้ง Node.js 20 ขึ้นไป แล้วเปิด START_SERVER.bat
  เจ้าของเครื่องเข้า http://localhost:3000
  เพื่อนเข้า http://IP-ของเครื่องเจ้าของ:3000
  ทุกคนเลือก เล่นกับเพื่อน และใช้เซิร์ฟเวอร์เดียวกัน
- ผ่านอินเทอร์เน็ต: ลงหน้าเกมบน GitHub Pages และเปิดเซิร์ฟเวอร์ Node.js
  ที่รองรับ HTTPS เพิ่ม หรือใช้เซิร์ฟเวอร์ Node.js เสิร์ฟทั้งหน้าเกมและห้อง
- สร้างห้อง → เพื่อนค้นหาห้องหรือกรอกรหัส 6 ตัว → ทุกคนกด พร้อมรบ
  → เจ้าของห้องกด เริ่มรบทั้งทีม
- ระบบรองรับ 1–4 ผู้เล่น ที่ว่างเติม AI จอยเพิ่มได้ขณะรอเริ่มรอบ
- หลุดเกิน 3 วินาที AI คุมแทน กลับเข้าด้วยเซสชันเดิมภายใน 90 วินาทีได้
- ออนไลน์ยังเดินเวลาขณะเปิดเมนู เจ้าของห้องพักเวลาให้ทั้งทีมได้

GitHub Pages ให้บริการหน้าเกมอย่างเดียว ไม่รันเซิร์ฟเวอร์ห้อง Node.js
ในชุดนี้มีเซิร์ฟเวอร์และไฟล์ตั้งค่าครบ แต่ยังไม่ได้เปิดบริการออนไลน์ให้
อย่าอัปโหลดเพียง ZIP ไปที่ Pages ให้อัปโหลดไฟล์ภายในโฟลเดอร์ IRON_TIDE
รวมโฟลเดอร์ .github แล้วเลือก Settings → Pages → Source: GitHub Actions

ข้อมูลและเซฟ
เครดิต เรือ และอัปเกรดเก็บในเบราว์เซอร์ของผู้เล่นแต่ละคน
กด สำรองข้อมูล เพื่อดาวน์โหลด JSON และใช้ โหลดข้อมูล / เซฟ เมื่อต้องการย้ายเครื่อง
เซฟรบอัตโนมัติมีเฉพาะเล่นคนเดียว ทุก 10 วินาทีและขณะออก/พัก
ออนไลน์เก็บห้องในหน่วยความจำเซิร์ฟเวอร์ รีสตาร์ตเซิร์ฟเวอร์แล้วห้องหาย
เมื่อย้ายจากไฟล์ออฟไลน์ไปเว็บไซต์ ให้สำรองข้อมูลแล้วนำเข้าในเว็บไซต์ใหม่
เซฟเวอร์ชัน 1 ใช้กับเวอร์ชัน 2 ไม่ได้

ไฟล์สำคัญ
START_GAME.html             เกมออฟไลน์รวมไฟล์เดียว

MANUAL_TH.html              คู่มือเกมและการออกแบบระบบ
DEPLOY_GITHUB_TH.html       วิธีขึ้น GitHub Pages และเปิดห้องออนไลน์

server/server.cjs           เซิร์ฟเวอร์ห้อง Co-op แบบ Node.js ไม่มี dependency

tests/                      ทดสอบเกม กราฟิกเชิงคำนวณ และหลายผู้เล่น
tools/build_release.py      สร้างไฟล์รวมและ ZIP ใหม่ ใช้ Python 3

ถ้าภาพหรือเสียงมีปัญหา
ลองลดคุณภาพภาพ เปิดการเร่งกราฟิก และเปิดใน Chrome/Edge
หากไม่มี WebGL ยังสั่งการผ่านแผนที่ยุทธวิธีได้
เสียงเริ่มหลังการคลิกครั้งแรก ตรวจปุ่ม เสียง และระดับเสียงของเครื่อง
ถ้าปุ่มลัดไม่ทำงาน ให้ออกจากช่องพิมพ์แล้วคลิกพื้นที่เกม
ใช้ปุ่มสัมผัสบนจอได้ แต่คอมพิวเตอร์พร้อมเมาส์และคีย์บอร์ดควบคุมสะดวกกว่า

เกมต้นแบบอิสระที่ได้แรงบันดาลใจจากยุทธนาวีปะทะเอเลียน
โมเดลและเสียงสร้างขึ้นใหม่ ความสมจริงเป็นฟิสิกส์และกราฟิกแบบเกม
ไม่ใช่เกมทางการหรือกราฟิกระดับภาพยนตร์
ผลตรวจสอบและขอบเขตการทดสอบอยู่ใน docs/VALIDATION.md
