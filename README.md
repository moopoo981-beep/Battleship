# IRON TIDE II — Fleet Command

เกมยุทธนาวี 3D ภาษาไทย ขับเรือหนึ่งลำร่วมกับพันธมิตร AI หรือเล่น Co-op กับเพื่อนสูงสุด 4 คน เวอร์ชัน 2.0

## เข้าเล่น

แยก ZIP แล้วเปิด **START_GAME.html** ด้วย Chrome หรือ Edge → เลือกเรือ → เริ่มภารกิจ → เข้าปฏิบัติการ เล่นคนเดียวได้แบบออฟไลน์ ไม่มี CDN หรือแพ็กเกจที่ต้องติดตั้ง

**WASD** ขับเรือ · **Q** โซนาร์ · คลิกศัตรูแล้ว **L** ล็อกหลายเป้า · **G** ปืนใหญ่ · **M** จรวด · **T** ตอร์ปิโด · **F** สกัด · **R** ซ่อม · **Space** พักเวลา · **Esc** เมนู

## ระบบในเวอร์ชันนี้

- ควบคุมเฉพาะเรือของตัวเอง AI เดินเรือและยิงสนับสนุน
- เรือ 5 แบบ พร้อมร้านค้า เครดิต และอัปเกรดติดเรือ
- แมพ 36 × 36 ช่อง ภารกิจ 3 ด่าน ความยาก 3 ระดับ
- ลำเรือ 3D มีรายละเอียด ป้อมปืนหมุน/ยก/ถอย แสง คลื่นและรอยน้ำ
- การเร่งและชะลอ แรงเฉื่อย หางเสือ โคลงตามคลื่น และชนเกาะ
- ปืนวิถีโค้ง จรวดนำวิถี ล็อกสูงสุด 6 เป้า และตอร์ปิโด
- เอเลียนกระโดดหลบ โดรนใบจักร และการพังของโดม
- เป้าที่ถูกทำลายหลุดจากล็อก/เรดาร์ และหายหลังจม
- ดนตรีและเสียงสังเคราะห์ ปรับแยกดนตรี/เอฟเฟกต์และปิดทั้งหมดได้
- ห้องสาธารณะหรือรหัสส่วนตัว ผู้เล่น 1–4 คน AI เติมช่องว่าง และกลับเข้าเรือลำเดิมหลังหลุด

## เล่นกับเพื่อน

ติดตั้ง Node.js 20 ขึ้นไป แล้วเปิด **START_SERVER.bat** บน Windows หรือรันจากรากโครงการ:

```sh
node server/server.cjs
```

เข้า **http://localhost:3000** → เล่นกับเพื่อน → สร้างห้อง / เข้าด้วยรหัส → พร้อมรบ → เจ้าของเริ่มเกม เพื่อนใน LAN ใช้ IPv4 ของเครื่องที่รันเซิร์ฟเวอร์แทน localhost

**GitHub Pages ให้บริการหน้าเกม ส่วนห้องออนไลน์ใช้เซิร์ฟเวอร์ Node.js แยกที่มี HTTPS** มีไฟล์ workflow, Dockerfile และ render.yaml แนบมา ยังไม่มี backend ที่ deploy ให้โดยอัตโนมัติ

ทำตาม [คู่มือ GitHub Pages และออนไลน์](docs/DEPLOY_GITHUB_TH.md) หรือเปิด **DEPLOY_GITHUB_TH.html** จาก ZIP ตั้ง URL backend ใน **dist/config.js** หรือช่องเซิร์ฟเวอร์ในเมนูเล่นกับเพื่อน

อัปโหลดไฟล์ภายใน IRON_TIDE ให้ dist และ .github อยู่ที่ราก repo จากนั้น Settings → Pages → Source: GitHub Actions ใช้ workflow ที่แนบมาเผยแพร่โฟลเดอร์ dist

## เซฟและอัปเกรด

เครดิตและเรือเก็บในเบราว์เซอร์ กด **สำรองข้อมูล** เพื่อดาวน์โหลด JSON และ **โหลดข้อมูล / เซฟ** เพื่อย้ายไปเครื่องหรือโดเมนใหม่ อัปเกรดมีผลในรอบถัดไป เซฟรบอัตโนมัติมีเฉพาะโหมดคนเดียว

ห้องออนไลน์เก็บในหน่วยความจำเซิร์ฟเวอร์ รีสตาร์ตแล้วห้องหาย โปรไฟล์ไม่ได้ซิงก์ผ่านบัญชีส่วนกลาง ระบบเหมาะกับ Co-op กับเพื่อน ไม่ใช่เศรษฐกิจการแข่งขันที่ป้องกันการแก้ไขเครดิต เซฟ v1 ไม่รองรับ v2
